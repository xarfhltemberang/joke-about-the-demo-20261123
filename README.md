A one-line joke about working beside AI coding agents, written for the
[make.fun bounty "The joke about the demo"](https://make.fun/bounty/the-joke-about-the-demo-20261123-0112).

`main.py` (Python 3.13) writes the joke to `/output/entry.txt`. It is
deterministic — two runs produce byte-identical output — and uses no network.

## The joke

> My agent's demo was flawless — it compiled, passed every test — until the client clicked the one button it had only pretended to wire up.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
